# Field Shift brand

The sun rises over shifting crop rows, watched by a satellite in orbit: farm decisions from NASA Earth data.

| File | Use |
|---|---|
| `logo-icon.svg` / `png/logo-icon-512.png` | App icon, favicon, avatar (also 192 and 1024 px) |
| `logo-horizontal.svg` / `png/logo-horizontal.png` | Logo with name, on light backgrounds |
| `logo-horizontal-white.svg` / `png/logo-horizontal-white.png` | Logo with name, on dark backgrounds |
| `banner.svg` / `png/banner.png` | README header, GitHub social preview (1280 × 640), slides |

Use the PNG files where fonts may not load (GitHub, slides, social media). The SVG files use Space Grotesk.
